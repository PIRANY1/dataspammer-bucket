# Scoop Bucket for DataSpammer

## Install
Dataspammer or 
``` batch
scoop bucket add dts-bucket https://github.com/PIRANY1/dataspammer-bucket
scoop install dataspammer
```
DataSpammer DE

``` batch
scoop bucket add dts-bucket https://github.com/PIRANY1/dataspammer-bucket
scoop install dataspammerde
```
